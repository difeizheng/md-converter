Markdown 平台转换器

粘贴一篇 Markdown 文章，一键生成头条号 / 知乎 / 公众号三平台适配版本。纯本地处理，内容不出浏览器。规则确定性转换，不联网、不调用 AI。

命令行版（开源，功能更全）

本页是 md2posts 命令行工具的网页精简版。CLI 版支持批量目录转换、代码块保护、表格转换，仓库见 GitHub（搜索 md2posts）。

三个版本各做了什么（转换规则公开）

头条号版：生成 3 个标题备选；段落按句子切到 100 字内；小节标题加 ▍ 标记；剥离 Markdown 语法；按关键词生成话题标签。

知乎版：保留标题层级与论证结构；结论前置（首段第一句加粗为「先说结论」）。

公众号版：顶部显示估算阅读时长；标题转粗体；正文中的清单项自动汇总成文末「今日行动清单」；— END — 收尾。

全部为确定性规则转换：不联网、不调用 AI、不改写你的内容。

常见问题

内容会被上传吗？
不会。全部转换在你的浏览器内完成，断网可用，页面关闭即消失。
转换后还需要人工做什么？
三件事：①头条版从 3 个标题备选里挑一个；②通读一遍确认语义没有被段落切分破坏；③配图（本工具不处理图片）。
支持哪些 Markdown 语法？
标题（#/##/###）、粗体、列表、引用、分隔线、表格。代码块会原样保留。图片语法暂不处理（v2 计划）。
